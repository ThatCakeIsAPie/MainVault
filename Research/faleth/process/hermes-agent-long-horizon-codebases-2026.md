# Hermes Agents on Long-Horizon Codebases (2026)

## Signal

Public demo: **AI agents + Hermes** applied to **reviving a dead MMORPG** across a huge legacy codebase (~50M LOC narrative). Proof-point that agent stacks are being used for **multi-session, multi-file, recovery-style engineering**, not just greenfield toys.

## Faleth implications

- Long-horizon work needs **loops** (stop conditions, verification), not chat sprints.
- Prefer **modular recovery**: map system → delete dead paths → rebuild interfaces — Elon Algorithm applied to legacy code.
- Content/ops: Hermes as **orchestrator brand** is spreading; Lyle's stack is on the same curve.
