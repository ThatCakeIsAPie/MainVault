# Segmented Buyer Psychology — Sell the Outcome

## Provenance

Distilled from @eagleseyeinc ([X status 2073037005051642038](https://x.com/i/status/2073037005051642038)), forwarded by Lyle via Telegram 2026-07-05. Raw: [[research/raw/transcripts/lyle-x-share-2073037005051642038]].

## Core principle

**People buy identity transformation and emotional jobs, not feature lists.** Map the buyer segment → dominant fear/aspiration → promised outcome. Deliver the outcome with real capability or the frame is manipulation.

### Segment → emotional job (reference table)

| Segment | Sell (emotional job) | Not the object |
|---------|----------------------|----------------|
| Cash-strapped / time-trapped | A **way out** | “Automation package” |
| Wealth-preserving | **Safety** | “Insurance product” |
| Young / early career | **Potential** | “Course access” |
| Late career / family legacy | **Legacy** they leave | “Consulting hours” |
| Employees | Freedom from the **boss** | “Side hustle tool” |
| Owners / bosses | Freedom from **employees** (ops drag) | “HR software” |

Thread corollary: drill → **hole**; watch → **status**; course → **confidence**; gym → **body**; bed → **sleep**; insurance → **peace of mind**.

## Faleth application (Lyle / Delta)

### Three Ps mapping

- **Push (pain at 3am):** paycheck dependence, zero-leverage day job, GovCon payment lag, manual proposal grind.
- **Pull (who they want to become):** agency-respecting builder, operator with systems, contributor with ownership path.
- **Process (what they enjoy):** modular workflows, compression, automation that *feels* like winning the game of operations.

### Offer packaging

1. **Automation bridge services (~$800/wk target):** headline = *hours back + income that doesn’t need permission* — not stack names (n8n, Zapier).
2. **GovCon pipeline:** COs buy **risk reduction, compliance, deliverability** (institutional safety), not “we use AI.”
3. **Faleth Capital narrative:** **agency and voluntary alignment** — freedom from arbitrary dependence — not “family office” jargon.

## Guardrails (from thread criticism)

- Stereotype-only targeting fails; still must **solve a real problem**.
- Faleth standard: criticism must build — offer a better path, not vibe-based manipulation.
- Use segment table as **discovery checklist**, not excuse to skip product truth.
