# Biography Operating System

**Purpose**: Turn biographies into compressed, reusable strategic intelligence for Faleth Capital.

**Core Thesis**: Personal experience is too narrow. Hundreds of lives = a council of ghosts you can consult.

## Extraction Schema

Every biography is reduced using a standardized template covering:
- Core Drive
- Arena
- Constraints
- Repeated Patterns
- Failure Modes
- Decision Models
- Faleth Relevance
- Key Scenes & Quotes

Optional high-leverage fields include Mentorship Compression, Agency Preservation, Timing Mastery, Betrayal Handling, and Legacy Architecture.

## Integration

All extracted notes are tagged #faleth-relevant and linked into Faleth documents. GBrain can answer questions such as which leaders preserved contributor agency best or what patterns appear in multi-generational institution builders.

System created June 2026. Template available. First biographies to process TBD.
