## Retrieved repository context

The linked MIT-licensed repository describes fourteen supported formats: DOC/DOCX/DOCM, PPT/PPS/POT/PPTX/PPTM/PPSX/PPSM, XLS/XLSX/XLSM/XLSB, ODT/ODS/ODP, RTF, EPUB, CSV, and PDF. Inputs feed format-specific parsers and then a shared document model/GitHub-Flavored-Markdown serializer; text PDFs use `pdf-inspector`. Interfaces include Rust, Node.js, Python, browser-WASM, CLI, and an agent skill. The repository reports a 4.4 ms median and quality score 81 over its private 100-document benchmark, with an LLM judge; these remain first-party measurements and should be reproduced on the actual corpus.
