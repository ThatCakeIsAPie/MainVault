# Teknium — Hermes Agent Streaming TTS

**Author:** Teknium (@Teknium)  
**Posted:** 2026-07-29T05:34:47Z  
**Source:** https://x.com/i/status/2082339029375426914

> Voice chats in Hermes Agent are now way faster, most API provided TTS backends will stream their speech so you get closer to real time interactions!

## Attached diagram

The diagram contrasts traditional full-reply synthesis with the new streaming path:

- LLM token stream → clause/sentence splitter → streaming TTS provider → PCM chunks → local speaker or an opted-in platform adapter.
- Speech can begin after the first complete clause instead of waiting for the entire answer and full audio file.
- True chunked providers shown: ElevenLabs, Gemini SSE, OpenAI, and xAI WebSocket.
- Local/synchronous providers such as Edge, Piper, NeuTTS, and Kitten retain sentence-level or whole-file fallback behavior.

## Stack-specific observation

On Lyle's Hermes VPS after the update, `tts.provider` is configured as `xai`, local faster-whisper `base` handles STT, `voice.auto_tts` is enabled, and Hermes resolves `XAIStreamer` through the available xAI OAuth credentials. Telegram remains a file/voice-message surface rather than a true live PCM conversation. The practical real-time surface is Hermes Desktop or CLI/TUI on a machine with microphone and speakers, connected to the existing Hermes backend.
