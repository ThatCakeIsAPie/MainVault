## Official docs (retrieved 2026-09-01)

Help page exists: https://help.obsidian.md/cli (permalink `cli`; source `Extending Obsidian/Obsidian CLI.md`).

Verified claims from that page, not from the tweet:

- Official CLI for scripting, automation, and external tools. TUI plus one-shot `obsidian <command>`.
- Requires the **1.12 installer**, specifically **1.12.7+**. Enable in Settings → General → Command line interface, then PATH registration.
- Obsidian app must be running; first command launches it if not. Headless sync is a separate product path.
- Commands cover daily notes, search, tasks, Bases query/create, files (create/read/append/move/rename/delete with wikilink updates), backlinks, properties, plugins, templates, sync, publish, developer/CDP/`eval`.
- Windows: installer 1.12.7+ plus `Obsidian.com` terminal redirector next to `Obsidian.exe`; PATH takes effect after a new terminal.

Tweet said “1.12.0.” Docs say 1.12 installer / 1.12.7+. Do not treat the tweet version as the install bar.
