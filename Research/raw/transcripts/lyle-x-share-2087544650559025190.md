## Same-author benchmark context

Minutes earlier, 0xSero specified the system behind the claim:

- **Hardware:** 4 × NVIDIA RTX PRO 6000
- **Model:** DeepSeek-V4-Flash-0731
- **Runtime:** DS4 / DwarfStar inference engine, surfaced through Local Studio and Litter
- **Single-stream decode:** **407 tok/s**
- **Eight-session aggregate decode:** **1,387 tok/s**
- **Total KV/context capacity claimed:** **5 million tokens**

A respondent reported only 190 tok/s single-session and 1.7M KV cache on the same class of server with r31 and vLLM; 0xSero said he would share configuration details. Therefore the numbers are practitioner claims with the exact DS4 configuration still pending, not yet a reproducible benchmark recipe.

## Component roles

- **DS4 / DwarfStar:** model-specific inference engine. Its README lists CUDA multi-GPU support and DeepSeek V4 Flash as a primary target.
- **Local Studio:** local-first control plane for model backends and coding agents.
- **Litter:** native mobile client that streams reasoning, edits, and terminal/tool calls from Local Studio.

The 400 tok/s result belongs principally to the **four-GPU DS4 serving stack**. Litter and Local Studio make that compute operational from a phone; they do not create the raw inference throughput.

## Evidence classification

- Post, video, and same-author benchmark details: directly observed from X API/media.
- Performance: author-reported, high specificity, but not independently reproduced.
- Broader significance: local open-weight inference can now feel cloud-instant when specialized runtimes, large-memory multi-GPU hardware, and a low-friction mobile agent surface are integrated.
