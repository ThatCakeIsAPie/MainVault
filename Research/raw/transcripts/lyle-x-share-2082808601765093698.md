## Interpretation

This is unusually strong bundled value: the specialized Cursor-model allowance absorbed a reported 648,015,199 tokens while leaving the separate Other Models allowance untouched. The screenshot supports “at least $20 of API usage,” although it should not be treated as a fungible external API cash credit without checking Cursor's current plan terms.

The reported token count is a user-side observation, not an audited billing comparison. Input/output mix, caching, internal token accounting, promotional limits, and model-specific economics can make 648 million bundled tokens very different from buying 648 million uncached frontier-model API tokens at list price.

## Rough API-equivalent value (checked 2026-07-30)

The official xAI Grok 4.5 model page lists **$2.00 per million input tokens**, **$6.00 per million output tokens**, and **$0.30 per million cached-input tokens**. Requests with at least 200,000 prompt tokens are priced at double those standard input/output rates.

For 648,015,199 total tokens:

- All cached input: **$194.40**.
- All ordinary input: **$1,296.03**.
- 90% input / 10% output: **$1,555.24**.
- 80% input / 20% output: **$1,814.44**.
- 70% input / 30% output: **$2,073.65**.
- All output: **$3,888.09**.
- If the traffic qualified for long-context pricing, the 80/20 case would be **$3,628.89**.

A reasonable ordinary-API estimate is therefore roughly **$1,500–$2,100**, or about **78–104× the $20 subscription**, before accounting for heavy cache reuse. The absolute conservative floor—pretending every token was a cache read—is still about **$194**, nearly 10× the plan price.

Pricing source: [xAI Grok 4.5 model documentation](https://docs.x.ai/developers/models/grok-4-5).

## Durable takeaway

Evaluate subscriptions by **accepted work per fixed monthly dollar**, not merely nominal token price. When a plan provides a deep model-specific pool plus a separate general-model allowance, route bulk execution through the subsidized pool and reserve flexible premium usage for tasks that actually require it. Exploit the economics while keeping the harness provider-swappable; subsidies are wonderful right up until a pricing department notices them.
