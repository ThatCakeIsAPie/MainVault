## Cross-Industry Patterns
- **The bottleneck has moved from generation to closure:** agents create code/backlogs, models create drafts, media tools create clips, and ownership systems create promises. Value arrives only when accepted work, receipts, measured outcomes, or enforceable rights close the loop.
- **Pricing is becoming multidimensional:** Opus effort and Fast tiers, provider service tiers, media routers, and free/promo routes all require cost per accepted result—not sticker price or model prestige.
- **Governance is operational metadata:** repository provenance, ISR evidence paths, media provenance, compliant claims, acquisition operator assignment, and participant information/appeal rights are all versions of the same control problem.
- **Labels are increasingly cheap:** `agentic`, `compliant`, `employee-owned`, `AI-generated`, and `fast` are not outcomes. Require observable mechanisms.
