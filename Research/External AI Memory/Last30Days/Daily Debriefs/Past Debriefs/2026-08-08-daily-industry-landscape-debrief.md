## Cross-Industry Patterns

- **Protocols are becoming governed action layers:** Mortgage MCP, advertising MCP, auction MCP, GovCon workflow products, and model routers all point toward narrow action surfaces over systems of record rather than generic chat interfaces.
- **Authority inheritance matters:** the useful systems preserve permissions, compliance context, named owners, approval thresholds, and audit receipts. Agent capability without bounded authority is merely a faster incident generator.
- **Distribution is commoditizing capacity:** OpenRouter keeps hundreds of model routes; creative platforms keep adding the same video models; GovCon vendors package the same public data. Durable value moves to domain memory, acceptance tests, source traceability, workflow fit, and measurable outcomes.
- **Labels do not specify economics:** “MLM,” “employee owned,” “MCP,” “batch,” and “AI proposal automation” each hide materially different rights, incentives, risks, and controls. Mechanism-level inspection remains the antidote.
