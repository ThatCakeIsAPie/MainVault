## Cross-Industry Patterns
- **The wrapper is becoming the product:** Guidewire's agent harness, OpenRouter's route catalog, hosted H3 access, GovCon evidence lockers, and ownership vehicles all mediate access to a capability. The wrapper determines permissions, economics, jurisdiction, evidence, and failure handling.
- **Availability is not authorization:** An API row means routable, not production-ready; open weights mean downloadable, not legally usable everywhere; an agent can collect CMMC evidence without being compliance authority; an ownership label can exist without meaningful control or liquidity.
- **Vertical context beats generic intelligence:** Insurance agents need policy/claims/billing integration; GovCon agents need clauses, data categories, flowdowns, and receipts; LTD leadership needs approved claims and IDS context; Faleth ownership needs explicit formulas and authority.
- **Accepted-result economics remain the KPI:** Token price, video-second price, model size, labor-reduction claims, and ownership rhetoric are inputs. Count accepted outputs, supervision, corrections, compliance, latency, cash timing, and downstream outcomes.
