# External AI Memory

Drop memory files, context dumps, and conversation exports from other AI assistants here.

Delta will read files in this folder as reference material when relevant to conversations.

## Usage

- Drop `.md`, `.txt`, or `.json` files from other AIs (Claude, ChatGPT, Gemini, etc.)
- Name them descriptively — e.g., `Claude - Project X Context.md`
- Delta checks this folder when cross-session context is needed
