# Systems, Habits, and Scoreboard Playbook

## Job

Make growth inevitable instead of mood-dependent. Decide on the **work**, not the result. Confidence is purchased with evidence.

## Personal OS (non-negotiables for builders)

| Habit | Standard |
|---|---|
| Conversations | 10 / active day (baseline) |
| Opens | 3 / active day |
| MG1 bookings | 4 / week |
| MG1s run | ~10 / month personal |
| Audios | 2–3 LTD system audios / day |
| Reading | 30 min or 30 pages print |
| Affirmations | written, time-bound, 2–3×/day |
| Association | Night Owl / FNL / room as scheduled |
| Body | exercise as identity infrastructure |
| Upward comms | before you "feel like it" |
| Tracking | same-day log of leading indicators |

Active year assumption: 5 days/week × 50 weeks = 250 operating days.

## Three blocks (Anderson framing via Gordon Night Owl)

1. **Action** — meetings, customers, personal use, conversations.
2. **Fuel** — reading, listening, associating.
3. **Loop** — accountability, coaching, communication.

Fuel without Action is cosplay. Action without Fuel burns out. Action without Loop repeats blind mistakes.

## Weekly scoreboard (print this)

### Leading inputs

- Conversations: ___ / 50 (baseline week)
- Opens: ___ / 15
- MG1s booked: ___ / 4
- MG1s run: ___
- Customers / personal circle PV notes: ___
- Audios / reading days hit: ___
- Association events attended: ___
- Upline communications: ___

### Pipeline conversions

- Booking → show rate: ___
- Show → next step rate: ___
- Run MG1 → sponsor rate (rolling): ___

### Lagging (monthly)

- Sponsors this month: ___
- Active legs / hard runners: ___
- Org MG1s in depth: ___
- PV / structure notes: ___
- One bottleneck sentence: ___
- One coaching question: ___

## Daily battle sheet (compact)

Elevate hook Lyle already named—keep it small:

1. New conversations
2. Opens
3. MG1s booked / run
4. Follow-ups
5. Customers / customer PV
6. Sponsors / depth movement
7. Read / audio / exercise / system
8. One qualitative note (bottleneck / lesson)

Do not build dashboard theater. One sheet, honest numbers.

## Diagnostics when the month is off

Use pipe stage + WKRP before self-prosecution:

1. Work volume too low?
2. Knowledge gap on language/process?
3. Right people / hunger?
4. Posture (defending, needy, image)?
5. Which conversion stage failed?

"Your feelings lie; your numbers don't." Numbers locate the leak; coaching explains it.

## Environment and calendar

- Calendar is proof of priorities.
- Association is selected peer pressure—morally neutral, deliberately chosen.
- One bad day is an accident; two can become a pattern.
- Protect inputs when emotion wants renegotiation.
- Independent thinking: do not outsource destiny to unhungry circles; also do not reject people as identity theater.

## Desire management

Empty tank ≠ broken person. Refill with association, reading, listening, small wins (customer, better conversation, one more open). Breakthroughs are felt through reps, not explained into existence.

## Season-aware application (Lyle)

- Maintain the scoreboard even when LTD is not primary cash engine—character and skill still compound.
- Do not let conference intensity become a substitute for VXE execution.
- If capacity is limited, protect **minimum viable funnel + association** rather than fake all-in volume that collapses honesty.
